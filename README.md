# UCコンディションノート

潰瘍性大腸炎の方向けに、毎日の症状を記録し、臨床的重症度と最近の経過の**目安**を確認できるスマートフォン対応Webアプリです。

## 主な機能

- 排便回数、水様便、血便、便意切迫感、夜間排便の記録
- 体温、脈拍、腹痛、Hb、CRP、赤沈などの記録
- 厚生労働省の指定難病に用いられる6項目を参考にした軽症・中等症・重症の基準表示
- 「医師に伝えるメモ」と「自分用メモ」の保存・履歴表示
- 直近7件から「寛解方向／活動性上昇の可能性／横ばい」を表示
- 緊急サインと受診・連絡目安の表示
- 記録のCSV出力
- 端末内保存（サーバーへの送信なし）
- PWA対応（ホーム画面への追加・オフライン表示）

## 重要な注意

このアプリは診断、治療、服薬変更を行うものではありません。表示結果だけで薬を増減・中止せず、主治医の指示を優先してください。重症度の正式な判断や寛解の確認には、診察、内視鏡、血液・便検査などが必要です。

## 判定の考え方

「1日5回以上の排便」は中等症の基準の1項目ですが、便回数だけでは中等症・重症は確定しません。本アプリでは、軽症・中等症・重症の各基準を示し、排便回数、顕血便、発熱、頻脈、貧血、赤沈またはCRPを組み合わせて参考表示します。

以前のバージョンで保存した「メモ」は、医師に伝えるメモとして引き継ぎます。

## 起動方法

```bash
python3 -m http.server 8000
```
